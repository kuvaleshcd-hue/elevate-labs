# 🔐 Elevate Labs Cybersecurity Internship

This repository contains my **Cybersecurity Internship tasks completed as part of the Elevate Labs internship program**.

The tasks focus on practical cybersecurity concepts including network scanning, vulnerability assessment, phishing analysis, firewall configuration, and password security.

## 📌 About the Internship

The internship provided hands-on experience with cybersecurity tools, techniques, and security best practices.

Through these tasks, I worked on identifying security weaknesses, analyzing potential threats, and implementing basic security measures.

## 🛠️ Tasks Covered

### Task 1 – Network Scanning

* Performed network reconnaissance.
* Used **Nmap** to identify hosts and open ports.
* Analyzed services running on discovered ports.
* Learned basic network enumeration techniques.

### Task 2 – Phishing Analysis

* Studied common phishing techniques.
* Analyzed suspicious emails and links.
* Identified indicators of phishing attacks.
* Learned methods to recognize social engineering attempts.

### Task 3 – Vulnerability Assessment

* Studied common system and application vulnerabilities.
* Identified potential security weaknesses.
* Learned basic vulnerability assessment techniques.
* Documented security findings.

### Task 4 – Firewall Configuration

* Worked with firewall concepts.
* Created and analyzed firewall rules.
* Studied inbound and outbound traffic filtering.
* Learned how firewalls help protect systems and networks.

### Task 5 – Cybersecurity Analysis

* Practiced cybersecurity concepts through practical exercises.
* Analyzed security-related scenarios.
* Applied basic security assessment techniques.

### Task 6 – Password Strength

* Developed a password strength assessment.
* Analyzed password characteristics.
* Checked password complexity.
* Evaluated factors such as:

  * Password length
  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
* Learned the importance of strong password policies.
